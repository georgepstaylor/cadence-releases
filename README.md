# Cadence releases

Signed and notarized builds of [Cadence](https://george.dev/projects/cadence), a macOS calendar that gets you into your calls on time.

Download `Cadence.zip` from the [latest release](https://github.com/georgepstaylor/cadence-releases/releases/latest), unzip it, and move Cadence to Applications. Once installed, Cadence updates itself.

This repository only hosts release builds and the update feed (`appcast.xml`). The source code is private.

Privacy policy: <https://george.dev/projects/cadence/privacy>
